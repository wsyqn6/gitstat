功能特性

多维度的 Git 数据洞察工具

Multi-Repo

多仓库扫描

自动扫描指定目录下所有包含 .git 的仓库，支持增量扫描与懒加载，快速发现全部代码库。

Dashboard

今日看板

实时展示今日提交数、增删行数、活跃作者等概览数据，按仓库和作者逐日展开明细。

Analytics

分析中心

每日提交趋势、代码变更分布、开发者排行榜、活动热力图、仓库雷达对比，全方位洞察。

Heatmap

活动热力图

按星期 × 小时维度展示团队编码活跃时段，快速识别高效工作时间段。

Comparison

仓库对比

通过雷达图从提交数、代码量、活跃天数等多维度对比各仓库的活跃度。

Export

数据导出

一键将全量扫描数据导出为 JSON 文件，便于二次分析和存档备份。

界面预览

赛博朋克风格的可视化界面

快速开始

一分钟启动可视化面板

STEP 01

启动服务

指定待扫描目录，启动 HTTP 服务：

$ gitstat serve D:/work --port 12580
STEP 02

打开浏览器

访问本地地址，即可进入仪表盘：

→ http://localhost:12580
STEP 03

探索数据

浏览看板、切换时间范围、筛选仓库，多维度分析提交活动。
